# Moroccan Skin Care — Wholesale & Private Label B2B Platform

A modern, high-performance B2B wholesale and export platform for authentic Moroccan organic skincare products, including cosmetic & culinary argan oil, prickly pear seed oil, Moroccan black soap (beldi), ghassoul clay, blue nila, aker fassi, and damask rose water.

## 🚀 Key Features

- **Trilingual Localization (i18n)**: English (`/en`), French (`/fr`), and Arabic (`/ar`) with full RTL (Right-to-Left) typography and layouts.
- **B2B Wholesale Catalog**: Comprehensive product specifications (INCI, CAS, extraction method, origin, certifications, MOQs, and bulk packaging options).
- **Educational Knowledge Base & Blog**: Detailed guides on traditional Moroccan beauty rituals, extraction methods, and export compliance.
- **Ultra-Fast Performance**: Built with Next.js 16 (Turbopack), Tailwind CSS, Lucide Icons, and optimized WebP visual assets.
- **cPanel / Apache Static Export Ready**: Includes custom static export optimizations and `.htaccess` routing rules.

## 📦 Tech Stack

- **Framework**: Next.js 16 (App Router, Static Site Generation)
- **Styling**: Tailwind CSS
- **Localization**: next-intl (EN, FR, AR)
- **Deployment**: Static Export (`output: "export"`)

## 🛠️ Development & Build

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production static export
npm run build
```
